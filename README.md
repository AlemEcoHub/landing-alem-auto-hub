# Alem Auto Hub — лендинг

Одностраничный лендинг приложения для автовладельцев Казахстана.
**Next.js 14 (App Router) + TypeScript + Tailwind CSS**, две языковые версии
(русская и казахская), mobile-first вёрстка.

## Запуск

```bash
npm install
npm run dev        # http://localhost:3000 → редирект на /ru
```

Продакшн:

```bash
npm run build
npm run start
```

## Логотип и иконки

Исходник фирменного знака — `public/logo-source.png`. Весь набор иконок
собирается из него одной командой:

```bash
npm run icons
```

Скрипт `scripts/make-icons.mjs` вырезает знак «A» из верхней части логотипа,
обрезает по фактическим краям и раскладывает по размерам:

| Файл | Где используется |
| --- | --- |
| `app/favicon.ico` | вкладка браузера (16/32/48/64 в одном файле) |
| `app/icon.png`, `app/apple-icon.png` | Next подключает автоматически |
| `public/icon-192.png`, `public/icon-512.png` | `app/manifest.ts`, экран «Домой» |
| `public/logo-mark.png` | знак в шапке сайта (`components/Logo.tsx`) |

Логотип нарисован на чёрном фоне, поэтому альфа берётся как `max(R, G, B)` —
для сведённой на чёрный картинки это точная маска: цвета не выцветают, края
остаются сглаженными, а вырезы внутри «A» остаются вырезами. Если пришлют
новый логотип — положить его в `public/logo-source.png` и перезапустить
команду. `public/og.png` пересобирается вручную.

## Шрифты и иконки

Заголовки — **Onest**, текст — **Golos Text** (обе через `next/font/google`,
подключены сабсеты `cyrillic` и `cyrillic-ext`, поэтому казахские буквы не
подменяются системным шрифтом). Иконки — **@tabler/icons-react**: у набора есть
настоящая автомобильная группа (гараж, двигатель, подъёмник, масло). Все иконки
проходят через `components/Icons.tsx` — там задана толщина линии и имена, так
что заменить глиф можно в одну строку.

## Тексты и языки

Весь видимый текст лежит в `lib/i18n/ru.ts` и `lib/i18n/kk.ts` — в компонентах
строк нет. Казахский словарь типизирован как `Dict = typeof ru`, поэтому
`npm run build` падает, если в переводе не хватает ключа или он назван иначе.

Внутри строк можно выделить часть текста фирменным градиентом двойными
скобками:

```ts
title: "Всё о вашем автомобиле — [[в одном приложении]]"
```

Акцент ставится отдельно для каждого языка — там, где он уместен по смыслу,
а не там же, где в русском.

Города и типы бизнеса хранятся парами `{ value, label }`: `label` переводится,
`value` всегда остаётся русским, чтобы заявки в CRM приходили единообразно.

### Добавить третий язык

1. Создать `lib/i18n/xx.ts` по образцу `kk.ts` (тип `Dict` подскажет ключи).
2. Добавить код в `LOCALES` и `LOCALE_META` в `lib/i18n/config.ts`.
3. Зарегистрировать словарь в `lib/i18n/index.ts`.

Роуты, sitemap, hreflang и переключатель языка подхватят его автоматически.

## Скриншоты приложения

`public/screens/*.png` — экраны, приведённые к единому формату 390×844
(экран iPhone). Исходные скролл-скриншоты разной длины лежат рядом в `public/`;
нормализованные версии собраны из верхней части экрана и родной нижней панели
приложения. Компонент `PhoneFrame` рисует все мокапы одного размера и с одним
соотношением сторон — новые скриншоты нужно готовить в том же формате 390×844.

## Структура по ТЗ

Главная объясняет систему, детали живут на внутренних страницах — так, как
описано в `ТЗ · Visual Content Wireframe`.

| Маршрут | Что на нём |
| --- | --- |
| `/[locale]` | 11 экранов: Hero → Проблема → Экосистема → Digital Garage → Светофор → Auto Box → Автопарки → Подрядчики → Партнёрам → Источники данных → Финал бренда |
| `/[locale]/drivers` | Подробности для автовладельца |
| `/[locale]/business` | Компании, автопарки и дорожная карта проекта |
| `/[locale]/partners` | СТО, сервисы и магазины |
| `/[locale]/privacy` | Черновик политики конфиденциальности |

Экраны главной лежат в `components/sections/home/`, внутренние страницы
собираются из `components/sections/pages/`.

### Truth-check

`components/StatusBadge.tsx` помечает функциональность как «Работает»,
«В разработке» или «В планах» — по требованию ТЗ ничего невыпущенное не
показывается как готовый факт. Статусы задаются в словаре
(`drivers.features.*.status`), госданные помечены отдельно в блоке
«Источники данных».

### Три аудитории

У B2C, автопарка и партнёра свои CTA и свои формы: `LeadType` в
`components/ModalProvider.tsx` принимает `owner | fleet | partner`, а
`app/api/lead/route.ts` валидирует все три.

## Движение

Восемь анимаций в автомобильной стилистике, по одной на секцию — чтобы две
никогда не играли в одном экране. Каждая запускается один раз, когда блок
попадает в зону видимости (`components/motion/useInView.ts`), и использует
только `transform` и `opacity`.

| Компонент | Что делает | Где |
| --- | --- | --- |
| `DashboardLamps` | Лампы приборной панели загораются и гаснут в зелёный | Конец «Проблемы» |
| `Instruments` (`Gauge` + `Odometer`) | Стрелка со сбросом и барабаны пробега | «Решение» |
| `HeadlightText` | Луч фар высвечивает заголовок | Все заголовки секций |
| `VerifiedStamp` | Печать впечатывается в кадр | «История обслуживания» |
| `ScanCar` | Сканирующая линия отмечает узлы | Auto Box |
| `RoadSpine` | Дорога с машинкой, которая едет по мере прокрутки | Левое поле, от `xl` |

`HeadlightText` рисует три копии заголовка: приглушённую, обычную под маской-лучом
и тёплую под узким «окном» света. Свет ложится только на буквы — на фоне не
остаётся ни свечения, ни пятна.

Ключевые кадры лежат в `app/globals.css` в блоке «Motion kit», разметка — в
компонентах. При `prefers-reduced-motion: reduce` каждая анимация показывает
свой конечный кадр без движения, а дорожная разметка скрывается.

## Формы заявок

Две формы (автовладелец / партнёр) открываются в модальном окне из любой
CTA-кнопки. Данные уходят на `POST /api/lead` вместе с текущей локалью.

**Куда приходят заявки** — задаётся через переменные окружения (`.env`):

- `TELEGRAM_BOT_TOKEN` + `TELEGRAM_CHAT_ID` — сообщение в Telegram.
- `LEAD_WEBHOOK_URL` — POST JSON в Google Sheets / CRM / Make / n8n / email.

Если переменные не заданы — заявка валидируется и пишется в серверный лог.
Скопируйте `.env.example` в `.env` и заполните.

## Аналитика

`lib/analytics.ts` отправляет события в `gtag`, `fbq`, `ym` и `dataLayer`.
Отслеживаются: `cta_*_click`, `form_start`, `lead_*_submit`, клики по
WhatsApp/Telegram, переключение языка и просмотры секций (scroll depth).

UTM-метки, referrer и страницу входа `captureAttribution()` запоминает один
раз за сессию и подмешивает к каждому событию и к каждой заявке — поэтому
источник виден и в аналитике, и в самом лиде.

## Что заменить перед запуском

- Контакты и ссылки — `lib/content.ts` (телефон, WhatsApp, Telegram, email).
- Канал доставки заявок — `.env`.
- ID счётчиков аналитики — `app/[locale]/layout.tsx`.
- Текст политики конфиденциальности — `legal.*` в словарях, сейчас черновик.
- Статусы READY / MOCKUP / VISION — `drivers.features.*.status` в словарях.
